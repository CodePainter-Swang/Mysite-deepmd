# AI for Science: 基于深度势能的分子动力学模拟平台

Welcome to the AI for Science project, a powerful tool for conducting molecular dynamics simulations using deep learning models. This project leverages the capabilities of DeepMD to simulate complex molecular systems with high accuracy and efficiency.

## Features

- **User-Friendly Interface**: Easily configure and run simulations through a web-based interface.
- **Customizable Simulations**: Adjust parameters such as temperature, timestep, and boundary conditions to suit your needs.
- **Advanced Output Options**: Enable trajectory, force, and RDF outputs with customizable frequencies.
- **Dynamic Atom Type Configuration**: Add and configure atom types dynamically based on the selected molecular system.
- **Real-Time Monitoring**: Track simulation progress and performance metrics in real-time.

## Getting Started

To get started with the AI for Science project, follow these steps:

1. **Clone the Repository**:
   ```bash
   https://github.com/CodePainter-Swang/Mysite-deepmd.git
   ```

2. **Install Dependencies**:
   Ensure you have Python and the required packages installed. You can use the following command to install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Application**:
   Start the web server to access the simulation interface:
   ```bash
   python manage.py runserver 8000
   ```

4. **Access the Interface**:
   Open your web browser and navigate to `http://localhost:8000` to start configuring and running simulations.
